# Small files stored encrypted with an item.
% file notes/recovery.txt
synthetic recovery codes: 1111 2222 3333
% end
$ pm new --locked --key {root}/vault.key
? 0

Open it with `pm unlock`.
$ pm unlock --key {root}/vault.key

$ pm --password-stdin add --no-copy --name Example --username alice
