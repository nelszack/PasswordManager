# The life of a login item: add, find, change, revisions, trash and restore.
$ pm new --locked --key {root}/vault.key
? 0
Vault "Personal vault" ([..].enc) created and left locked.
Open it with `pm unlock`.
$ pm status
? 0
Status: Locked (run `pm unlock` to open your vault)
Version: 0.1.0
$ pm unlock --key {root}/vault.key
? 0
Vault unlocked.
$ pm --password-stdin add --no-copy --name Example --username alice --url https://example.com/login --tag work
< synthetic-password-1
? 0
Added "Example".
$ pm --password-stdin add --type secure-note --name "Wifi notes" --notes "router in hall closet"
< synthetic note body
? 0
Added "Wifi notes".
$ pm list
? 0

$ pm search exam

$ pm search --tag work
