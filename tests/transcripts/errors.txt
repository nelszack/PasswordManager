# Failures have stable exit codes and actionable messages.
$ pm get Example
? 1
! Error: No vault yet. Create one with `pm new --name NAME` (it starts the background server for you).
$ pm --json get Example
? 1
{"code":1,"error":"No vault yet. Create one with `pm new --name NAME` (it starts the background server for you).","ok":false}
$ pm new --locked --key {root}/vault.key
? 0
Vault "Personal vault" ([..].enc) created and left locked.
Open it with `pm unlock`.
$ pm get Example
? 1
! Error: The vault is locked. Run `pm unlock`, then try again.
$ pm unlock --key {root}/vault.key
? 0
Vault unlocked.
$ pm get Missing
? 3
! Error: No item is named "Missing"
$ pm --json get Missing
? 3
{"code":3,"data":"no item is named \"Missing\"","error":"no item is named \"Missing\"","ok":false,"operation":null}
$ pm delete --id 999999
