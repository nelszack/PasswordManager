PM Command Reference

Generated from the same Clap metadata used by the pm executable. Run cargo run -- generate-command-reference after changing CLI definitions.

About this reference

Usage, command descriptions, options, and defaults below are generated. Run pm <COMMAND> --help for terminal help and available examples.

Global --port PORT overrides the configured loopback port for one invocation; --json wraps output in an object containing ok and output or error; --quiet suppresses successful output. --json and --quiet cannot be combined. See the README for setup, defaults, and workflows.

pm genpass

Generate a random password or passphrase without opening the vault

Usage: pm genpass [OPTIONS]
-l, --length <LENGTH>
Password length; defaults to the configured generator length
--no-stats
Hide password strength/statistics, overriding configuration Default: false.
--stats
Show password strength/statistics, overriding configuration Default: false.
--no-copy
Do not copy the generated value, overriding configuration Default: false.
--copy
Copy the generated value, overriding configuration Default: false.

Seconds before clearing the clipboard; defaults to clipboard configuration

Exclude ASCII uppercase letters
--no-lowercase
Exclude ASCII lowercase letters
--no-digits
Exclude decimal digits
--no-symbols
Exclude symbols

Use this exact symbol set instead of the built-in set
--exclude-ambiguous
Exclude visually ambiguous characters such as 0, O, 1, and l
--passphrase
Generate a word-based passphrase instead of a character password
--words <WORDS>
Number of words in a passphrase Default: 6.

Text placed between passphrase words Default: -.

pm unlock

Unlock a vault using a prompted master password or an existing key file

Usage: pm unlock [OPTIONS]
--vault-file <VAULT_FILE>
Open only this .enc filename from `pm vaults`, avoiding a full scan
--key <KEY>
Read the vault key from this file instead of prompting for a password. Relative paths resolve from the current directory.
--timeout <TIMEOUT>
Inactivity duration before automatic lock (for example 900, 15m, 1h, or 1d). Zero disables automatic locking for this unlock session. If omitted, uses the configured unlock timeout.

pm backup

Create or restore a complete encrypted vault backup

Usage: pm backup <COMMAND>

pm backup create

Export every vault record to a versioned encrypted backup. Without `--key`, prompts for a dedicated backup password. The backup includes recovery history, trash, TOTP configuration, and typed items.

Usage: pm backup create [OPTIONS] --path <PATH>

Destination backup file
--key <KEY_PATH>
Encrypt with an existing key file instead of a backup password
--force

Usage: pm backup restore [OPTIONS] --path <PATH>
--path <PATH>
Encrypted backup file to restore
--key <KEY_PATH>
Decrypt with a key file instead of a backup password
--force

pm get

Display item details, or print its primary secret with `--password-only`. Details redact the primary secret, notes, and secret custom fields. Use --reveal-secrets to display secret custom fields. The default form copies the primary secret when the configured clipboard timeout is nonzero.

Usage: pm get [OPTIONS] <--id <ID>|--entry-name <ENTRY_NAME>>
--id <ID>
Select an entry by its stable numeric ID
--entry-name <ENTRY_NAME>
Select an entry by exact name
--password-only
Print only the primary secret, without copying it to the clipboard
--reveal-secrets
Display secret custom-field values in item details
--field <FIELD>
Print only this custom field's value (case-insensitive name)
--copy
Copy the selected custom field instead of printing its value

pm import

Import CSV, JSON, Bitwarden JSON, or this application's portable JSON. By default imports into the unlocked vault. `--new` creates a separate locked vault using a prompted password or new key file.

Usage: pm import [OPTIONS] --path <PATH>
--path <PATH>

--new

--key <KEY_PATH>
Create the new imported vault's external key; requires `--new`
--preview

--conflicts <CONFLICTS>
How duplicate name/username/URL records are handled Default: skip.

pm export

Export the unlocked vault as portable JSON or interoperable CSV. A `.json` destination preserves rich metadata; other extensions use CSV. Both formats contain plaintext secrets and use private permissions.

Usage: pm export [OPTIONS] --path <PATH>
--path <PATH>
Destination file; `.json` selects portable JSON, otherwise CSV
--force
Atomically replace an existing plaintext export
