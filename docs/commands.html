Getting started

The CLI talks to a local background server. A typical password-based workflow is:

pm start
pm new
pm unlock
pm add --name github --username alice --url https://github.com
pm view
pm lock
pm kill

For a key-based vault, provide a key path to new and unlock. Explicit relative paths resolve from the current directory.

pm new --key ./keys/vault.key
pm unlock --key ./keys/vault.key
Help in the terminal: use pm --help or pm <command> --help. Global flags can appear before or after a subcommand.

Global options

These options are available with every public command, including local commands such as genpass, passcheck, config, and completions.

--port <PORT>
Use a different loopback port for this invocation. The client and server must use the same port. Does not change the config file.
--json
Wrap output in a stable JSON object for scripts. Conflicts with --quiet.
--quiet
Suppress successful output while still printing errors. Conflicts with --json.
-h, --help
Show command help.
-V, --version
Show the installed version.
pm --port 8787 start
pm --json view --sort name
pm --quiet lock

help

pm help [COMMAND] [SUBCOMMAND]

Show the same terminal documentation available through --help. Add a command and optional nested subcommand for more specific help.

pm help
pm help add
pm help backup restore

start, status, and kill

start launches the local server as a detached background process. status reports whether its vault is locked or unlocked. kill persists and locks the vault, then stops the server.

pm start
pm status
pm kill

# Use the same override for every server-backed command
pm --port 8787 start
pm --port 8787 status
pm --port 8787 kill

new

pm new [--key <PATH>]

Create an empty vault and leave it locked. Without a key file, the command securely prompts twice for a master password. init and create are aliases.

--key <PATH>
Create a new external key file. Relative paths resolve from the current directory; the key must remain outside application data.
pm new
pm new --key ./keys/vault.key

unlock and lock

pm unlock [--key <PATH>] [--timeout <DURATION>]

unlock opens a vault using a prompted master password or key file. lock encrypts the in-memory vault and removes key material from the server.

--key <PATH>
Read the vault key from a file instead of prompting. Use ./name.key for the current directory; a bare filename addresses a legacy app-data key.
--timeout <DURATION>
Override inactivity auto-lock for this session. Accepts seconds or s, m, h, and d suffixes. Zero disables auto-lock.
pm unlock
pm unlock --timeout 30m
pm unlock --key ./keys/vault.key
pm lock

rekey

pm rekey [--key <PATH>]

Re-encrypt the unlocked vault with a new master password or a newly created key file. The replacement is persisted before the old vault is removed.

--key <PATH>
Create and switch to a new external key. Existing external key files are never overwritten.
pm rekey
pm rekey --key ./keys/replacement.key

delete

pm delete (--id <ID> | --entry-name <NAME> | --vault) [OPTIONS]

Move one entry to encrypted trash, or permanently delete a complete vault.

--id <ID>
Move the entry with this stable numeric ID to trash.
--entry-name <NAME>
Move the entry with this exact name to trash.
--vault
Permanently delete an entire vault. Conflicts with entry selectors.
--key <PATH>
Use a key file to open the vault being deleted. Otherwise, the command prompts for its password.
--keep-key
Preserve the supplied key after deleting its vault. Requires both --vault and --key.

Whole-vault deletion and key-file deletion cannot be undone.

pm delete --id 12
pm delete --entry-name github
pm delete --vault
pm delete --vault --key ./keys/vault.key
pm delete --vault --key ./shared.key --keep-key

add

pm add --name <NAME> [OPTIONS]

Add a login or another typed secret to the unlocked vault. Unless generated, the primary secret is read through a private prompt.

--name <NAME>
Required display name used to identify and search for the item.
--username <USERNAME>
Login, email, cardholder, or other secondary identifier.
--url <URL>
Associate a URL. Repeat the flag for additional URLs; the first is primary.
--type <TYPE>
Item category. Defaults to login; see accepted values.
--notes <TEXT>
Free-form notes.
--field <NAME=VALUE>
Add a searchable custom field. May be repeated.
--secret-field <NAME>
Privately prompt for a custom-field value. May be repeated.
--generate-password
Generate the primary secret instead of prompting.
--copy
Copy the newly added primary secret.
--no-copy
Do not copy the new secret, overriding configuration. Conflicts with --copy.
pm add --name github --username alice --url https://github.com
pm add --name router --type wifi --field ssid=Home --secret-field passphrase
pm add --name api --type api-secret --generate-password

view

pm view [FILTERS]

List vault items without displaying their primary secrets. list and ls are aliases.

--type <TYPE>
Include only this item category.
--totp
Include only login items with an authenticator. Conflicts with --no-totp.
--no-totp
Include only login items without an authenticator.
--weak
Include only logins whose password is considered weak.
--stale-days <DAYS>
Show passwords at least this many days old.
--sort <FIELD>
Sort by id, name, created, modified, or password-age. Defaults to id.
--descending
Reverse the selected sort order.
pm view
pm view --type login --sort name
pm view --weak --descending

search

pm search [<QUERY>] [FILTERS]

Search metadata and optionally combine field, type, health, TOTP, stale-password, and sorting filters. A query or at least one filter is required.

<QUERY>
Case-insensitive text matched across name, username, URL, and notes.
--name <TEXT>
Require text in the item name.
--username <TEXT>
Require text in the username.
--url <TEXT>
Require text in a URL.
--notes <TEXT>
Require text in notes.
Listing filters
Also accepts every view filter: --type, --totp, --no-totp, --weak, --stale-days, --sort, and --descending.
pm search github
pm search --username alice --type login
pm search --no-totp --sort modified

get

pm get (--id <ID> | --entry-name <NAME>) [--password-only]

Display one item’s details or primary secret.

--id <ID>
Select by stable numeric ID.
--entry-name <NAME>
Select by exact name.
--password-only
Print only the primary secret without copying it to the clipboard.
pm get --id 4
pm get --entry-name github --password-only

update

pm update (--id <ID> | --entry-name <NAME>) [CHANGES]

Modify an existing item. Multiple compatible changes can be applied together.

--id <ID>, --entry-name <NAME>
Select the item by ID or exact name.
--name <NAME>
Replace the display name.
--username <USERNAME>
Replace the username or secondary identifier; an empty value clears it.
--password
Privately prompt for and replace the primary secret.
--generate-password
Generate the replacement secret. Requires --password.
--url <URL>
Replace the primary URL.
--notes <TEXT>
Replace notes; an empty value clears them.
--type <TYPE>
Change the item category.
--add-url <URL>
Add another URL. Repeatable; conflicts with --clear-urls.
--remove-url <URL>
Remove a matching URL. Repeatable; conflicts with --clear-urls.
--clear-urls
Remove every URL. Conflicts with URL replacement/addition/removal.
--field <NAME=VALUE>
Set a searchable custom field. Repeatable.
--secret-field <NAME>
Privately prompt for a custom-field value. Repeatable.
--remove-field <NAME>
Remove a custom field by case-insensitive name. Repeatable.
--clear-fields
Remove every custom field; conflicts with field changes.
pm update --id 4 --username alice@example.com
pm update --entry-name github --password --generate-password
pm update --id 7 --field environment=production --add-url https://example.com

history and restore-password

history lists saved password revisions. restore-password makes a listed revision current.

--id <ID>, --entry-name <NAME>
Select an entry by stable ID or exact name.
--revision <NUMBER>
Revision shown by history; required by restore-password.
pm history --entry-name github
pm restore-password --entry-name github --revision 2

trash, restore, and purge

trash lists deleted entries. restore returns one to the active vault. purge permanently erases one or all trashed entries.

restore --id <ID>
Restore the stable ID shown by pm trash.
purge --id <ID>
Permanently erase one trashed entry.
purge --all
Permanently erase every trashed entry.
pm trash
pm restore --id 12
pm purge --id 12
pm purge --all

audit

pm audit [OPTIONS]

Report weak, reused, duplicate, stale, breached, or under-protected login credentials. Secrets are not included in the report.

--stale-days <DAYS>
Report passwords at least this many days old.
--breaches
Privately check password hash prefixes against Pwned Passwords. Requires network access.
--require-totp
Report logins without a configured TOTP authenticator.
pm audit
pm audit --stale-days 180 --require-totp
pm audit --breaches

totp

Store, generate, or remove time-based one-time-password authenticators.

totp set --id <ID>
Privately prompt for a Base32 secret or otpauth:// URI. --entry-name may be used instead.
totp show --id <ID>
Generate the current authentication code.
--copy
With totp show, copy the code instead of only printing it.
--copy-time <SECONDS>
Clear the copied code after this many seconds. Requires --copy; otherwise uses clipboard configuration.
totp remove --id <ID>
Remove authenticator configuration. Every TOTP subcommand also accepts --entry-name.
pm totp set --entry-name github
pm totp show --entry-name github --copy --copy-time 20
pm totp remove --entry-name github

backup create and backup restore

Encrypted backups preserve the complete vault: item metadata, stable IDs, history, trash, and TOTP configuration.

--path <PATH>
Required destination for create, or encrypted input file for restore.
--key <PATH>
Encrypt or decrypt using an existing key file instead of prompting for a dedicated backup password.
--force
On create, atomically replace an existing backup. On restore, replace an existing vault associated with the backup password/key.
pm backup create --path vault.pmbackup
pm backup create --path vault.pmbackup --key ./backup.key --force
pm backup restore --path vault.pmbackup
pm backup restore --path vault.pmbackup --key ./backup.key --force

import and export

Import CSV, JSON, Bitwarden JSON, or portable PM JSON. Imports into the current unlocked vault preserve its lock state. Export writes portable JSON for a .json destination and CSV for other extensions, always with private file permissions.

import --path <PATH>
Required input file.
--new
Create and import into a separate locked vault instead of the currently unlocked vault.
--key <PATH>
Create the new vault's external key. Requires --new.
--preview
Show counts and conflicts without changing a vault or its lock state.
--conflicts <POLICY>
Use skip, replace, or keep-both. Defaults to skip.
export --path <PATH>
Destination file. .json selects portable JSON; other extensions select CSV. An existing file is replaced.

Exports contain plaintext secrets. Protect or remove them when finished.

pm import --path passwords.csv --preview
pm import --path passwords.csv --conflicts keep-both
pm import --path export.json --new --key ./keys/imported.key
pm export --path vault.json

genpass

pm genpass [OPTIONS]

Generate a random character password or word-based passphrase without opening the vault.

-l, --length <NUMBER>
Password length of at least one; defaults to generator configuration.
--stats, --no-stats
Show or hide strength statistics, overriding configuration.
--copy, --no-copy
Enable or disable copying, overriding configuration.
--copy-time <SECONDS>
Clipboard-clearing delay; defaults to clipboard configuration.
--no-uppercase
Exclude ASCII uppercase letters.
--no-lowercase
Exclude ASCII lowercase letters.
--no-digits
Exclude decimal digits.
--no-symbols
Exclude symbols.
--symbols <TEXT>
Use this exact symbol set instead of the built-in set.
--exclude-ambiguous
Exclude visually ambiguous characters such as 0, O, 1, and l.
--passphrase
Generate words instead of characters. Conflicts with length and character-set flags.
--words <NUMBER>
Passphrase word count of at least one; defaults to 6 and requires --passphrase.
--separator <TEXT>
Text between passphrase words; defaults to - and requires --passphrase.
pm genpass --length 24 --copy
pm genpass --passphrase --words 7 --separator .
pm genpass --no-symbols --exclude-ambiguous

passcheck

pm passcheck [--password <PASSWORD>]

Estimate password strength without storing it. With no flag, the password is read through a private prompt.

-p, --password <PASSWORD>
Provide the password as an argument for scripting. It may be visible to other processes or retained in shell history.
pm passcheck
pm passcheck --password 'correct horse battery staple'

config

pm config [OPTIONS]

Show or update persistent defaults. Boolean values are true or false. Missing settings in older files are automatically added with current defaults.

--reset
Restore every setting to its built-in default. Cannot be combined with setting overrides.
--length <NUMBER>
Default character-password length of at least one.
--stats <BOOL>
Whether generated passwords show statistics by default.
--copy <BOOL>
Whether generated passwords are copied by default.
--password-copy <BOOL>
Whether newly added login passwords are copied by default.
--clipboard-timeout <SECONDS>
Delay before copied values are cleared.
--unlock-timeout <DURATION>
Default inactivity auto-lock duration. Accepts seconds or s, m, h, and d; zero disables.
--password-history-limit <NUMBER>
Prior passwords retained per entry; zero disables history.
--trash-retention-days <DAYS>
Automatically purge older trash; zero disables expiration.
--server-port <PORT>
Default loopback port for the client, server, and browser native host.
pm config
pm config --server-port 8787 --unlock-timeout 30m
pm config --password-history-limit 20 --trash-retention-days 30
pm config --reset

native-host install

pm native-host install --extension-id <ID> [--browser <BROWSER>]

Install and register the native-messaging bridge for an unpacked Chrome-family extension.

--extension-id <ID>
Required 32-character ID shown on chrome://extensions.
--browser <BROWSER>
Registration target: chrome, chromium, or helium. Defaults to chrome.
pm native-host install \
  --extension-id abcdefghijklmnopabcdefghijklmnop \
  --browser chrome

Reload the extension afterward. On Windows, fully close the browser before reinstalling an upgraded native host.

completions

pm completions <SHELL> [--output <PATH>]

Generate shell completion definitions.

<SHELL>
Completion syntax: bash, elvish, fish, powershell, or zsh.
--output <PATH>
Destination file. Defaults to -, which writes to standard output.
pm completions bash --output ~/.local/share/bash-completion/completions/pm
pm completions fish --output ~/.config/fish/completions/pm.fish
pm completions powershell --output pm.ps1

Accepted values

Item typeslogin, secure-note, payment-card, identity, wifi, software-license, ssh-key, api-secret
Sort fieldsid, name, created, modified, password-age
Import conflictsskip keeps the current item; replace uses the import; keep-both imports another named item.
DurationsWhole seconds such as 900, or suffixes such as 30s, 15m, 1h, and 1d.

Entry selectors

Commands that operate on one item accept exactly one of:

--id <ID>
The stable numeric ID shown by view, search, or trash.
--entry-name <NAME>
An exact item name.

This applies to get, update, history, restore-password, and all totp subcommands. delete also supports these selectors.

Internal commands

pm run runs the server process, and pm native-host run runs the browser’s binary native-messaging protocol. They are intentionally hidden from normal help and should not be launched manually; use pm start and pm native-host install.
