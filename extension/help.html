Password Manager help

Set up · Fill and save · Toolbar popup · Clipboard · Shortcuts · Troubleshooting

Set up

  1. Install the desktop app (the pm program): download the archive for your system from the releases page and run pm, or build it with cargo build --release --locked. Then create or open a vault.
  2. In the desktop app, open Settings → Browser & service → Set up browser integration, choose your browser, and select Turn on browser integration. From a terminal, run pm native-host install --browser chrome (or chromium, helium, firefox).
  3. Reload this extension. Its toolbar popup shows Unlocked while your vault is open.

On Windows, fully close the browser before turning on integration. The extension ID is fixed, so nothing needs copying; only a repackaged extension needs --extension-id.

Fill and save

  • Select the key button in a login field to choose a saved account. A separate window shows exactly which site will be filled, so a page cannot trick you into filling it.
  • Card and identity fields have their own buttons; one-time code fields have a clock button.
  • The ✨ button on sign-up forms suggests a strong password.
  • After you sign in with a new or changed password, a window offers to save or update it. You can review and correct the captured password there, or choose Never for this site.
  • Autofill works only on encrypted (https://) pages.

Toolbar popup

  • Logins for this site: fill one into the page, or copy its username, password, or one-time code.
  • Search all items: find any item by name, username, or website and copy its username, password, or one-time code. Open shows the item in the desktop app, where you can view, edit, or delete it. Search sees names and addresses, never passwords.
  • Add saves a new login for the current site, with a generated password or one you already have.
  • The popup never asks for your master password. Unlock in the desktop app; the popup updates by itself.

Clipboard

Passwords and codes are copied by the desktop app, which clears the clipboard after the time set in its Settings → Security (and never if copying is turned off there). If the desktop app isn't connected, the popup asks before copying a generated password, because nothing can clear it afterwards.

Keyboard shortcuts

  • Ctrl+Shift+Y (⌘+Shift+Y on macOS) opens the popup.
  • Ctrl+Shift+L (⌘+Shift+L on macOS) chooses a login for the focused field.
  • In the account window, type to search, use ↑ ↓ and Enter, or Esc to cancel.

Change shortcuts at chrome://extensions/shortcuts (Chrome) or about:addons → ⚙ → Manage Extension Shortcuts (Firefox).

Troubleshooting

Not connected
Browser integration isn't turned on for this browser, or the desktop app moved. Turn it on again (see Set up), then reload the extension. After updating the desktop app, choose Repair after an update or run pm native-host update.
Service stopped
The desktop app's background service isn't running. Open the desktop app to start it.
Locked
Choose Unlock in desktop app: the desktop window comes forward with its password field ready. Open popups, account and passkey windows continue by themselves once it unlocks.
Update needed
The extension and the desktop app are different versions. Update the one that is older.
Reconnecting…
The extension restarted in the background. Close and reopen the popup.
No key button on a page
The page isn't encrypted (http://), or its form isn't recognized. Use the popup's Copy username and Copy password instead.
“Fill” from the popup did nothing
The login form is inside an embedded frame. Use the key button in the field instead.
